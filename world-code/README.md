# World Code compact

`worldCode.js` is generated from `src/worldCode.js`, `src/utils/scheduler.js`, and `src/dungeon/generator.js`.
Do not edit it by hand; edit `src/` and run `npm run build` (or leave `npm run watch` running).

Copy the entire `worldCode.js` file into Bloxd World Code. It is bundled into one
script and contains no imports, so no separate scheduler file needs to be pasted.
